# Three.js 3D Data Visualization - Kasatria Assignment

Interactive 3D Data Visualization web application built with Three.js (CSS3DRenderer), fetching dynamic data from Google Sheets API with Google OAuth 2.0 authentication.

## 🚀 Live Demo
[View Live Project on Vercel](https://kasatria-assignment-neon.vercel.app/)

## ✨ Features
- **Authentication:** Google OAuth 2.0 Sign-In Integration.
- **Dynamic Data:** Real-time data parsing from Google Sheets CSV.
- **3D Layouts:** Interactive Table, Sphere, Helix, and Grid visualizations powered by Three.js.
- **Custom UI Styling:** Aesthetic dark-mode UI with sharp-edged neon glowing cards based on Net Worth grouping.
- **Responsive Layout:** Dynamic UI adaptable across desktop and mobile devices.

## 🛠️ Tech Stack
- HTML5 / CSS3
- JavaScript (ES6+)
- Three.js (CSS3DRenderer)
- Google Identity Services (OAuth 2.0)
